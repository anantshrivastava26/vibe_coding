General Instructions
1. This is an **individual activity**. Group work is not allowed.
2. The activity will be conducted for **two class periods**.
3. Students must bring:
   * Their own laptop
   * Laptop charger
   * Internet connection or mobile hotspot
4. Students may use Vibe Coding tools such as ChatGPT, Gemini, Claude, Cursor, Replit, Bolt, Lovable, or similar tools.
5. Students must manage the available tokens properly. Token exhaustion will not be accepted as a reason for incomplete work.               Students are advised to use free or open-access AI models whenever possible.
6. The problem statement will be shared only on the day of the activity.
7. Students must complete the application during the allotted time.
 
## Mandatory LMS Submission
Students must submit the following in the LMS using the given report template:
1. **Project Report**
2. **GitHub link containing the source code**
3. **Video demonstration of the application**
4. **Prompts used during development**
5. **Learning reflection**
 
The video must include:
* Application demonstration
* Voice-over explanation
* Student video/camera turned on
* Features developed
* Problems or blockers faced
* Experience gained from the activity
 
## Submission Deadline
 
Students will be given **two days after the activity** to upload the report and all required files in the LMS.
 
No extension will be provided.
 
Students who fail to submit within the deadline will be awarded **zero marks**.
 
## Evaluation
 
The activity will be evaluated for **100 marks**.
 
The marks obtained will later be converted to **5 marks** for academic mark entry.
